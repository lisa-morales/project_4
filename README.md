# Car Sales Data Dashboard

## Project Description
This web application dashboard allows users to explore and analyze car sales advertisement data through interactive visualizations. Users can examine relationships between different car features like vehicle price by type of vehicle, days listed vs type, vehicle price vs mileage, and comparison of popularity of paint color over time through histograms and scatter plots.

## Features
- Interactive histograms showing distribution of car features
- Scatter plots revealing relationships between variables
- Checkbox filters to customize data views
- Clean, user-friendly interface built with Streamlit

## Libraries and Tools Used
- **Streamlit** - Web application framework
- **Pandas** - Data manipulation and analysis
- **Plotly Express** - Interactive data visualizations
- **Python** - Core programming language

## How to Run Locally
1. Clone this repository to your local machine
2. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```
   streamlit run app.py
   ```
4. Open your browser and go to the URL shown in the terminal
